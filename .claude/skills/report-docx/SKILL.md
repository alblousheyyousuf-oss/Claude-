# بناء ملف التقرير

تحويل `report.md` إلى `report.docx` بأداة واحدة:

```bash
python3 .claude/skills/report-docx/scripts/build_report.py report.md -o out/report.docx --preview out/preview
```

الأداة مبنية على مهارة `arabic-docx` (مثبّتة بجانبها، وترخيصها MIT). بالعربية تستعمل `ArabicDocx` كما هو، وبالإنجليزية تستعمل نسخة منه من اليسار لليمين. فاللغتان تشتركان في التنفيذ نفسه للفهرس، والتسميات المرقمة، والجداول، وترقيم الصفحات، وخطوط العربية.

**المتطلبات:** `python-docx` و`PyYAML`، ومعهما LibreOffice أو Microsoft Word للمعاينة وحدها.

## 1. ملف Markdown

ابدأ من القالب:

| اللغة | القالب |
|---|---|
| العربية | `assets/report-template-ar.md` |
| الإنجليزية | `assets/report-template-en.md` |

### رأس الملف (Front matter)

بيانات الغلاف: `university` · `college` · `department` · `logo` · `report_type` · `title` · `subtitle` · `course` · `section` · `authors` (قائمة فيها `name` و`id`) · `instructor` · `instructor_label` · `semester` · `date`.

إعدادات التنسيق (القيم الافتراضية بين قوسين):

| المفتاح | المعنى |
|---|---|
| `lang` | `ar` أو `en` (تُستنتج من العنوان إن لم تُذكر) |
| `font` · `cs_font` · `size` | الخط اللاتيني (Times New Roman) · الخط العربي (Simplified Arabic) · الحجم (14 للعربية، 12 للإنجليزية) |
| `line_spacing` | التباعد بين الأسطر (1.5) |
| `margins_cm` · `page_size` | الهوامش (2.5) · `A4` أو `Letter` |
| `justify` | ضبط الفقرات من الجهتين (true) |
| `first_line_indent_cm` | إزاحة أول سطر (0) |
| `number_headings` | ترقيم العناوين 1. ثم 1.1 ثم 1.1.1 (true) |
| `chapter_page_break` | كل عنوان رئيسي في صفحة جديدة (true) |
| `toc` · `list_of_figures` · `list_of_tables` | فهرس المحتويات (true) · قائمة الأشكال · قائمة الجداول (false) |
| `figure_caption` | `below` (الشائع) أو `above` (APA 7) |
| `header_text` | نص قصير أعلى كل صفحة |
| `word_limit` | الحد المطلوب، فيطبع الفرق عند البناء |
| `cover` | إظهار الغلاف (true) |
| `template` | قالب Word من الجامعة، فتُستعمل أنماطه وهوامشه ورأسه وتذييله |

### جسم التقرير

| الكتابة | النتيجة |
|---|---|
| `#` إلى `####` | عناوين بأنماط Word الحقيقية (Heading 1–4)، فتظهر في الفهرس وجزء التنقل |
| `# الملخص {-}` | عنوان بلا رقم. وهذا تلقائي لـ: الملخص، والشكر، والمراجع، والملاحق، وAbstract، وReferences، وAppendix… |
| `**غامق**` · `*مائل*` | تنسيق داخل السطر |
| `- عنصر` · `1. عنصر` | قوائم حقيقية. وكل قائمة مرقمة تبدأ من 1 |
| `> نص` | اقتباس مزاح من الجهتين |
| جدول بخطوط `\|` | جدول بعرض أعمدة محسوب، وصف عناوين مظلل يتكرر في كل صفحة |
| `جدول: العنوان` أو `Table: Title` فوق الجدول أو تحته مباشرة | تسمية مرقمة «الجدول 1: …» فوق الجدول |
| `![العنوان](figures/x.png){width=14}` | شكل في الوسط، وتسمية مرقمة تحته، والعرض بالسنتيمتر |
| `[TOC]` | مكان الفهرس (افتراضياً بعد الغلاف). ضع الملخص قبله إن أردت |
| `\newpage` | فاصل صفحة |
| فقرات تحت عنوان «المراجع» أو «References» | مسافة معلّقة 1.27 سم. والمرجع الإنجليزي داخل تقرير عربي يُكتب من اليسار لليمين تلقائياً |
| `<!-- تعليق -->` | إرشادات للكاتب لا تظهر في الملف |

## 2. التحقق: انظر إلى الصفحات

```bash
python3 .claude/skills/report-docx/scripts/build_report.py report.md -o out/report.docx --preview out/preview
```

تطبع الأداة عدد كلمات الجسم، ونتيجة فحص `audit_docx` للعربية، وتحفظ صورة لكل صفحة. **افتح الصور بأداة Read وانظر إليها.** عيوب الاتجاه والخطوط لا تظهر في النص المستخرج، لأن الحروف صحيحة وموضعها خاطئ.

| افحص | المشكلة المعتادة |
|---|---|
| الغلاف في صفحة واحدة | عنوان طويل جداً أو طلاب كثيرون: قصّر العنوان، أو انقل العنوان الفرعي إلى الملخص، أو احذف حقلاً غير مطلوب |
| أول عمود في الجدول العربي على **اليمين** | — |
| المصطلحات الإنجليزية في مكانها، ومعها مسافاتها | `PostgreSQL و` لا `PostgreSQLو` |
| الأقواس سليمة | `(20 فأكثر)` لا `20) فأكثر(` |
| الشكل مع تسميته في الصفحة نفسها | — |
| لا صفحات فارغة | فاصل صفحة يدوي قبل عنوان رئيسي (العنوان الرئيسي يبدأ صفحة جديدة أصلاً) |
| ترقيم الصفحات يبدأ بعد الغلاف | — |

**عن الفهرس:** يمتلئ بأرقام الصفحات حين يفتح Word الملف ويوافق المستخدم على «تحديث الحقول». الملف مضبوط ليطلب ذلك. أما LibreOffice والمعاينة فتعرض العناوين بلا أرقام صفحات، وهذا متوقع. ذكّر المستخدم: في Word، انقر بالزر الأيمن على الفهرس ← تحديث الحقل ← تحديث الجدول بأكمله.

**عن الخطوط:** Simplified Arabic وTimes New Roman موجودان في Windows وOffice. وفي بيئة بلا هذه الخطوط تستبدلها المعاينة بخط آخر، فالمسافات تقريبية والاتجاه دقيق.

**عن LibreOffice:** في الفقرات المضبوطة من الجهتين قد يفصل LibreOffice القوس المفتوح عن المصطلح الإنجليزي الذي يليه في آخر السطر، مثل «التوليدي (» ثم «Generative AI)» في السطر التالي. هذا من طريقة LibreOffice في كسر الأسطر، وراجعه في Word قبل اعتباره عيباً.

## 3. قالب الجامعة

إن أعطى المستخدم قالب `.docx`:

```yaml
template: "university-template.docx"
```

تبقى أنماط القالب وهوامشه وحجم صفحته، ويُفرَّغ جسمه ورأسه وتذييله ثم يُملأ من Markdown. وإن كان في القالب غلاف مصمم (صور وإطارات)، فالأفضل تعطيل غلاف الأداة (`cover: false`)، ونسخ الغلاف من القالب يدوياً في Word، أو استعمال `insert_before` من `arabic-docx` لإضافة المحتوى بعد الغلاف.

**بعد أن يعدّل المستخدم الملف بيده في Word، لا تعِد بناءه من Markdown**، لأن تعديلاته ليست في المصدر. استعمل `ArabicDocx(template="report_v2.docx")` مع `insert_before()` للإضافة في مكانها (انظر `arabic-docx`).

## 4. ما لا تدعمه الأداة، وبدائله

| الحاجة | البديل |
|---|---|
| معادلات رياضية | pandoc: `pandoc report.md -o report.docx --reference-doc=styles.docx` (يحول `$…$` إلى معادلات Word). وللعربية بعده: `fix_docx(src, dst)` من `arabic-docx` |
| حواشٍ سفلية (Chicago) | pandoc أيضاً (`[^1]`)، أو إضافتها في Word |
| ترقيم روماني للصفحات التمهيدية | يتطلب فاصل مقطع (Section break). أضفه في Word: تخطيط ← فواصل ← الصفحة التالية، ثم تنسيق أرقام الصفحات |
| أعمدة متعددة، أو مربعات نص | Word يدوياً |
| PDF | المعاينة تنتج PDF في مجلد `--preview`. والأفضل للتسليم أن يحفظ الطالب PDF من Word بعد تحديث الفهرس |

## 5. اصطلاحات التنسيق الجامعي

القيم الشائعة إن لم يحدد القسم غيرها:

| العنصر | العربية | الإنجليزية |
|---|---|---|
| الخط | Simplified Arabic 14، أو Traditional Arabic 16 للنص، والعناوين أكبر بدرجتين | Times New Roman 12، أو Calibri 11 |
| التباعد | 1.5 | 1.5، أو 2.0 في APA |
| الهوامش | 2.5 سم (وقد تكون 3 سم في جهة التجليد) | 2.5 سم أو 1 بوصة |
| المحاذاة | ضبط من الجهتين | ضبط، أو يسار في APA |
| الترقيم | أسفل الوسط، وبلا رقم على الغلاف | أسفل الوسط، أو أعلى اليمين في APA |
| تسميات الجداول | فوق الجدول | فوق الجدول |
| تسميات الأشكال | تحت الشكل | تحت الشكل، أو فوقه في APA |
| كل جدول وشكل | مذكور في النص قبل ظهوره: «يوضح الجدول (1)…» | "As shown in Table 1…" |
