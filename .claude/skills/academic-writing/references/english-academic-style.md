# English Academic Style — Functions, Phrases and Common Errors

Phrases are tools for a function, not filler. Use one when it does a job: introducing evidence, contrasting, concluding. Do not repeat the same phrase on a page.

## 1. Phrases by function

| Function | Phrases |
|---|---|
| State the aim | This report examines… · The purpose of this report is to… · This report addresses the question of… |
| Report a source | Smith (2020) argues/found/reported that… · According to Smith (2020),… · As Lee (2019) notes,… |
| Agreement | Several studies have shown that… (A, 2019; B, 2021) · This finding is consistent with… |
| Contrast | In contrast,… · However, Lee (2021) found… · These results differ from… · Whereas X…, Y… |
| Addition | Furthermore,… · In addition,… · Moreover,… (sparingly) |
| Cause / association | This can be attributed to… · As a result,… (proven causation only) · X was associated with Y (correlation) |
| Example | For example,… · For instance,… · This is illustrated by… |
| Present results | Table 2 shows… · As Figure 1 illustrates,… · The mean score rose from… to… |
| Interpret | This suggests that… · One possible explanation is… · This may reflect… |
| Hedge (limited evidence) | may · might · appears to · tends to · is likely to · the data suggest |
| Conclude | Overall,… · Taken together, these findings indicate… · In summary,… |
| Recommend | It is recommended that [actor] [action]… · [Actor] should… |
| Limitations | This study was limited to… · The findings cannot be generalised to… · A limitation of this approach is… |

## 2. Reporting verbs: choose by strength

| Neutral | Stronger (author is confident) | Tentative | Critical |
|---|---|---|---|
| states, describes, notes, reports | argues, demonstrates, establishes, shows | suggests, proposes, speculates | claims, asserts (implies you doubt it) |

## 3. Common errors

| Avoid | Use | Why |
|---|---|---|
| don't, can't, it's | do not, cannot, it is | Contractions are informal |
| a lot of, big, get | many, substantial, obtain/become | Informal vocabulary |
| proves | supports, indicates | Single studies rarely prove anything |
| Research shows that… (no citation) | Research shows that… (Smith, 2020; Lee, 2021) | Every general claim needs sources |
| very unique, more optimal | unique, optimal | Absolute adjectives |
| data is | data are (APA) | Plural in APA style |
| e.g. lists ending with etc. | e.g., X and Y | Redundant |
| which / that confusion | that (restrictive), which (non-restrictive, with comma) | Meaning changes |
| Starting with "And" / "But" | However, … / In addition, … | Formal register |
| Rhetorical questions in body text | A direct statement | Reports state, not ask |

## 4. Sentence clarity

- Keep subject and verb close; split sentences over ~35 words.
- One idea per sentence; one claim per paragraph topic sentence.
- Replace nominalisations: *conduct an analysis of* → *analyse*; *make a decision* → *decide*.
- Name the referent: *This increase shows…*, not *This shows…*.
- Prefer active voice except where the actor is unknown or irrelevant (methods).

## 5. British vs American spelling

Pick one and keep it: *analyse/analyze*, *organisation/organization*, *behaviour/behavior*, *programme/program*. Follow the university's convention. Australian and UK institutions use British spelling, and US-oriented ones (and APA) American.
