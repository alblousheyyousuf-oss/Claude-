# التقارير الجامعية

مشروع لإعداد تقارير جامعية احترافية بالعربية والإنجليزية: من نص التكليف ومعايير التقييم، إلى ملف Word جاهز للتسليم، بمراجع حقيقية متحقَّق منها.

## كيف تبدأ

اكتب في جلسة Claude Code داخل هذا المستودع شيئاً مثل:

> عندي تقرير لمقرر MGT 201، هذا التكليف ومعايير التقييم: …

فتعمل مهارة `university-report` تلقائياً، وتمر بالمراحل التالية:

| # | المرحلة | ما يحدث | ما تحتاجه منك |
|---|---|---|---|
| 0 | الاستلام | أسئلة قليلة عمّا ينقص فقط | التكليف، ومعايير التقييم، والطول، وسياسة الذكاء الاصطناعي في المقرر |
| 1 | تحليل التكليف | ماذا يطلب كل فعل؟ وما وزن كل معيار؟ | — |
| 2 | المخطط | الأقسام، وميزانية الكلمات، وربط كل قسم بالمعايير | **موافقتك قبل الكتابة** |
| 3 | المصادر | البحث عن مصادر محكّمة، والتحقق من وجود كل مرجع | مراجع المقرر إن وُجدت |
| 4 | الكتابة | قسماً قسماً، وبلا اختلاق | بياناتك وتجربتك حيث يلزم |
| 5 | التوثيق | تنسيق المراجع، وفحص تطابقها مع النص | — |
| 6 | التنسيق | ملف Word بغلاف وفهرس وترقيم | قالب الجامعة إن وُجد، وشعارها |
| 7 | المراجعة | تقييم بالمعايير، وأعلى ثلاثة إصلاحات | — |

ويمكن طلب أي مرحلة وحدها: «راجع تقريري»، «سوّ لي المراجع APA»، «حوّله وورد بغلاف الجامعة».

## الأدوات

```bash
# ملف Word من Markdown (مع صور للصفحات للمعاينة)
python3 .claude/skills/report-docx/scripts/build_report.py report.md -o out/report.docx --preview out/preview

# هل المراجع موجودة فعلاً؟ (Crossref)
python3 .claude/skills/academic-citations/scripts/verify_refs.py report.md

# هل كل استشهاد له مرجع، وكل مرجع مستشهد به؟
python3 .claude/skills/academic-citations/scripts/check_citations.py report.md
```

المتطلبات: Python 3.10+، و`python-docx`، و`PyYAML`. ومعها LibreOffice أو Word للمعاينة فقط.

## ثلاث قواعد

1. **لا مرجع ولا بيانات مختلقة.** ما لا دليل عليه يبقى علامة ظاهرة، مثل `[مرجع مطلوب]` أو `[بيانات مطلوبة]`، حتى يُحل.
2. **التكليف ومعاييره وقالب الجامعة تتقدم** على كل إعداد افتراضي.
3. **سياسة الذكاء الاصطناعي في مقررك هي الحكم.** المهارات تسألك عنها، وتقترح نص إفصاح إن كان مطلوباً.

## الخصوصية

المستودع **عام**. ملفات تقاريرك تُحفظ في `university-reports/work/`، وهذا المجلد مستثنى من git (انظر `.gitignore`). فلا يُرفع اسمك ولا رقمك الجامعي ولا بياناتك.

**في الجلسات السحابية:** المجلد يُحذف عند انتهاء الجلسة. نزّل ملف Word النهائي قبل أن تغلقها.
