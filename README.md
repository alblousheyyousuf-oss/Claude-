## عن البروتوكول

خطة قائمة على الأدلة لتحسين التكوين الجسماني، مبنية على جدول تدريب «8 أسابيع» بمعدات جيم كاملة كقاعدة ثابتة. تغطي: المصفوفة الأيضية والماكروز، توقيت التغذية، الميكانيكا الحيوية والتدرّج، البروتوكول التصحيحي لساعات الجلوس، بروتوكول المكملات، التحسين العصبي والهرموني، ونظام العادات اليومية.

كل توصية رئيسية مصنَّفة بدرجة دليل (A / B / C).
